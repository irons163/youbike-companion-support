# YouBike Companion support

Public support and privacy pages for the independently developed YouBike
Companion iPhone/iPad app. Maintained by [Phil Chang](https://github.com/irons163).

- Website: https://irons163.github.io/youbike-companion-support/
- Support: https://irons163.github.io/youbike-companion-support/support.html
- Privacy: https://irons163.github.io/youbike-companion-support/privacy.html
- Contact: irons7654321@gmail.com

The site is plain HTML/CSS with no dependencies, analytics, or build step.
GitHub Pages serves the root of the `main` branch. `.nojekyll` preserves the
static files. Update the HTML directly, preview locally, then push to `main`.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

This repository contains the public website and issue templates only.
